# BT.GG.HT — Bố thí · Giữ giới · Hành thiền

App chung gồm 2 phần:
- **Bố thí** (`bothi.html`) — sổ cúng dường, đồng bộ hai chiều, cả nhà dùng chung.
- **Giữ giới - Hành thiền** (`thien.html`) — nhật ký thiền; điện thoại đẩy lên, máy tính chỉ tải về.

`index.html` là trang chung: một nút ⚙ Cài đặt (đồng bộ, mật khẩu, sao lưu, xuất/nhập) cho cả hai phần.
